# Contributing to Simple Interest Calculator

First off, thank you for considering contributing to the Simple Interest Calculator project! It's people like you that make open source such a great community.

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the project, please open an issue and include:
- A clear and descriptive title.
- Steps to reproduce the behavior.
- Expected vs. actual behavior.
- Any relevant logs or screenshots.

### Suggesting Enhancements
Enhancements to the script, documentation, or structure are always welcome! When suggesting an enhancement:
- Open an issue describing the requested feature.
- Explain why this enhancement would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Make sure your code adheres to standard Bash scripting practices.
3. Test your changes to ensure the interest calculation remains accurate.
4. Update the README.md with details of changes to the interface or usage if necessary.
5. Create a Pull Request with a clear description of the changes you've made.

## Documentation Improvements
Improving the documentation (like README.md, or this file) is just as important as writing code. Feel free to submit pull requests for fixing typos, adding missing information, or improving clarity.

## Code of Conduct
Please note that this project is released with a Contributor [Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
